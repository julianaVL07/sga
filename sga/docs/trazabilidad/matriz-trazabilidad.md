# Matriz de trazabilidad de reglas — SGA Apartahotel Coral (entrega 2)

Construida a partir del código: los mensajes de `ReglaDominioException` (cada uno empieza por el código de su regla),
los adaptadores REST de `infrastructure/rest` y las pruebas de `src/test`. Los códigos HTTP salen de ejecutar
`docs/api/sga.http` completo contra la aplicación recién arrancada (164 peticiones, todas pasan); el número entre
paréntesis es la petición de ese archivo que provoca el caso (por ejemplo, `409 (5.1)`).

Estado al cerrar las fases 1 y 2 de las tres integrantes: `./gradlew test --rerun` ejecuta **228 pruebas** (136
unitarias y 92 de integración) y todas pasan.

Convenciones:

- **Dónde se protege**: `Clase.método` del dominio que lanza la excepción o aplica la regla. `<constructor>` es el
  constructor compacto de un record (objeto de valor que no se deja construir inválido).
- **Pruebas unitarias**: `Clase#método` de `src/test/java/.../domain` (sin Spring, con los repositorios InMemory).
- **Pruebas de integración**: `Clase#método` de `src/test/java/.../infraestructure` (`@SpringBootTest` con MockMvc o
  datos iniciales).
- `—` en *Endpoint* indica que la regla no tiene un endpoint propio: se aplica al configurar el alojamiento
  (datos iniciales) o dentro de otro caso de uso sin un error propio. `—` en una columna de pruebas indica que no hay
  prueba de ese tipo.
